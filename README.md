# heat_sim

> **В разработке** — проект активно дорабатывается

Численное моделирование одномерной теплопроводности методом конечных объёмов с расщеплением по физическим процессам.

## Описание

Программа на языке C для решения уравнения теплопроводности в консервативной форме. Моделирует распределение температуры в медном стержне с учётом зависимости теплофизических свойств от температуры (интерполяция табличных данных).

**Курс:** Математическое моделирование, НИУ МЭИ, кафедра Низких температур
**Семестр:** Весна 2026 (8-й семестр)

## Теоретическая основа

### Вывод уравнения

Уравнение теплопроводности выводится из закона сохранения энергии в контрольном объёме с применением теоремы Остроградского-Гаусса. В классической форме:

```
∂T/∂t = α · ∂²T/∂x² + qv/(ρCv),    α = λ/(ρCv)
```

где α — коэффициент температуропроводности. Однако для численного решения удобнее **консервативная форма**, оперирующая объёмной плотностью энергии E = ρ·Cv·T:

```
∂E/∂t = ∂q/∂x + qv
```

Тепловой поток определяется **законом Фурье**: q = −λ·∂T/∂x.

### Аналитическое решение (для верификации)

Задача разделяется на стационарную u(x) и нестационарную v(x,t) части. Нестационарная часть раскладывается в ряд Фурье методом разделения переменных:

```
T(x,t) = u(x) + Σ Bₙ · sin(πn·x/l) · exp(−α·λₙ·t)
```

где λₙ = (πn/l)² — собственные значения, коэффициенты Bₙ находятся из ортогональности синусов.

### Дискретизация

Закон Фурье в дискретной форме:

```
q[i+½] = −λ[i+½] · (T[i+1] − T[i]) / h
```

| Параметр | Значение | Описание |
|----------|----------|----------|
| L | 1.0 м | Длина стержня |
| NC | 100 | Число расчётных ячеек |
| T(0, t) | 400 К | Температура на левом конце (ГУ 1 рода) |
| T(L, t) | 300 К | Температура на правом конце (ГУ 1 рода) |
| T(x, 0) | 300 К | Начальная температура стержня |
| τ | 0.1 с | Шаг по времени |
| t_end | 100 с | Время интегрирования |

## Метод решения

**Метод средних разностей** (конечных объёмов) с **расщеплением по физическим процессам** (метод Ричардсона). Область разбивается на ячейки с призрачными ячейками на границах для реализации ГУ 1 рода. Каждый временной шаг разделяется на два подшага:

```
Шаг 1 (потоки):    E[i]^(n+½) = E[i]^n − (τ/h) · (q[i+½] − q[i−½])
Шаг 2 (источники): E[i]^(n+1) = E[i]^(n+½) + τ · qv[i]
```

После обновления энергии пересчитывается температура T = E/(ρ·Cv) и теплофизические свойства вещества для следующего шага.

### Свойства вещества

Два режима работы (переключение через `USE_SPLINE` в `settings.h`):

| Режим | `USE_SPLINE` | Описание |
|-------|-------------|----------|
| Табличный | 1 | Линейная интерполяция ρ(T), Cv(T), λ(T) из `copper_properties.dat` |
| Постоянный | 0 | Фиксированные свойства меди: λ=401, Cv=386, ρ=8930 |

## Выходные данные

Программа выводит профиль температуры T(x) в конечный момент времени в stdout:
```
# x  T_numerical
0.005000 399.123456
0.015000 398.456789
...
```

Результаты можно визуализировать в gnuplot или Python (matplotlib).
