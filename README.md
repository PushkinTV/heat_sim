# heat_sim

> **В разработке** — проект активно дорабатывается

Численное моделирование одномерной теплопроводности методом конечных объёмов с расщеплением по физическим процессам.

## Описание

Программа на языке C для решения уравнения теплопроводности в консервативной форме. Моделирует распределение температуры в медном стержне с учётом зависимости теплофизических свойств от температуры (интерполяция табличных данных).

**Курс:** Математическое моделирование, НИУ МЭИ, кафедра Низких температур
**Семестр:** Весна 2026 (8-й семестр)

## Постановка задачи

### Уравнение теплопроводности (консервативная форма)

```
∂E/∂t = ∂q/∂x + qv
```

где E = ρ·Cv·T — объёмная плотность энергии, q — тепловой поток (закон Фурье), qv — объёмный источник тепла.

### Закон Фурье (дискретный)

```
q[i+½] = −λ[i+½] · (T[i+1] − T[i]) / h
```

| Параметр | Значение | Описание |
|----------|----------|----------|
| L | 1.0 м | Длина стержня |
| NC | 100 | Число расчётных ячеек |
| T(0, t) | 400 К | Температура на левом конце (ГУ 1 рода) |
| T(L, t) | 300 К | Температура на правом конце (ГУ 1 рода) |
| T(x, 0) | 300 К | Начальная температура стержня |
| τ | 0.1 с | Шаг по времени |
| t_end | 100 с | Время интегрирования |

## Метод решения

**Метод конечных объёмов** с расщеплением по физическим процессам (метод Ричардсона):

```
Шаг 1 (потоки):    E[i]^(n+½) = E[i]^n − (τ/h) · (q[i+½] − q[i−½])
Шаг 2 (источники): E[i]^(n+1) = E[i]^(n+½) + τ · qv[i]
```

### Свойства вещества

Два режима работы (переключение через `USE_SPLINE` в `settings.h`):

| Режим | `USE_SPLINE` | Описание |
|-------|-------------|----------|
| Табличный | 1 | Линейная интерполяция ρ(T), Cv(T), λ(T) из `copper_properties.dat` |
| Постоянный | 0 | Фиксированные свойства меди: λ=401, Cv=386, ρ=8930 |

## Сборка и запуск

```bash
make        # компиляция
./heat_sim  # запуск
make clean  # очистка
```

## Выходные данные

Программа выводит профиль температуры T(x) в конечный момент времени в stdout:
```
# x  T_numerical
0.005000 399.123456
0.015000 398.456789
...
```

Результаты можно визуализировать в gnuplot или Python (matplotlib).
