# heat_sim — Термоупругость мембраны SiO₂

Численное моделирование связанной задачи теплопроводности и прогиба тонкой мембраны из плавленого кварца (SiO₂), нагреваемой лазерным потоком.

**Курс:** Математическое моделирование, НИУ МЭИ, кафедра Низких температур
**Семестр:** Весна 2026 (8-й семестр)
**Преподаватель:** Терешкин В.С.

## Физическая постановка

Тонкая мембрана (толщина h = 1 мм, длина L = 1 мм) из SiO₂ нагревается лазерным потоком q₀(t) = A·(eᵗ−1) с обеих сторон по толщине. Неравномерный температурный профиль T(z,t) порождает тепловой изгибающий момент, который деформирует мембрану поперёк.

```
    лазер ↓  q₀(t)
  ══════════════════  z = +h/2
  │  T = T(z, t)   │
  ══════════════════  z = -h/2
    лазер ↑  q₀(t)
         → x, прогиб w(x,t)
```

## Метод решения

| Подзадача | Метод |
|-----------|-------|
| Теплопроводность по z | МКО, уравнение Каттанео (неявная схема), CFL-шаг |
| Прогиб по x | Спектральный Галёркин (базис — синусы Фурье) |
| Связь | Тепловой момент M(T) и жёсткость D(T) на каждом шаге |
| Газ (постобработка) | Конвекция Ньютона, итерация Re↔Nu |

## Сборка и запуск

```bash
make            # компиляция

python3 plot.py # графики
make clean      # очистка
```

## Результаты

При t = 20 с:
- T_top ≈ 659 K, T_bot ≈ 396 K
- Тепловой момент M ≈ 1.06 Н/м
- Термоупругий прогиб w_thermo ≈ 0.72 мкм (vs механический w_mech ≈ 10 нм)
- Воздушное охлаждение канала 0.1 мм при q₀ ≈ 5.3×10⁵ Вт/м² требует u_e ≈ 958 м/с (≈3 Маха) — конвекция воздухом неприменима
